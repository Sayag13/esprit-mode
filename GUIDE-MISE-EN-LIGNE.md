# Passer à la v1.0

Tout ce qui est en place reste identique : dépôt, Render, base Neon, données, comptes et mots de passe.

## 1. Envoyer les fichiers sur GitHub (comme pour la v0.9)
1. Décompressez **esprit-mode-v1.0.zip**.
2. Sur github.com/Sayag13/esprit-mode : **Add file**, puis **Upload files**.
3. Faites glisser tout le contenu du dossier, y compris le dossier `public`.
4. Message : `Version 1.0 – offres, vidéos, e-mails, SMS`, puis **Commit changes**.

## 2. Vérifier
Render déploie tout seul. Ouvrez https://esprit-mode.onrender.com/health : vous devez lire `"version":"1.0.0"`.

## 3. Activer l'envoi gratuit des e-mails (Brevo)
Cette étape est facultative : sans elle, tout le reste fonctionne.
Elle est guidée pas à pas dans la conversation.

## Au quotidien
- **Caisse :** choisissez une fois la boutique (Général de Gaulle ou Clemenceau) en haut à droite. Elle est retenue sur l'appareil et notée sur chaque achat.
- **Michelle, dans Clientes & communication :**
  - créer une campagne en cochant les canaux, puis utiliser les boutons de la campagne : « Envoyer l'e-mail », « SMS une par une », « WhatsApp une par une », « Afficher sur la carte des clientes », « Supprimer » ;
  - les SMS et WhatsApp se font **depuis son téléphone** : « Ouvrir » prépare le message, il reste à appuyer sur Envoyer ;
  - « Les vidéos de Michelle » : coller le lien d'une vidéo Instagram, Facebook ou YouTube. Elle apparaît sur la carte de toutes les clientes.
